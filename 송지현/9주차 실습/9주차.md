## 2. ScoreKeeper 스크립트 코드 작성

플레이어가 맞힌 문제 수와 지금까지 본 문제 수를 저장할 변수를 만든다.

```csharp
int correctAnswers = 0;
int questionsSeen = 0;
```

* `correctAnswers`: 맞힌 문제 수
* `questionsSeen`: 지금까지 푼 문제 수

이 변수들은 외부에서 직접 수정하지 않도록 private 상태로 두고, Getter와 Setter 역할을 하는 메서드를 통해 접근한다.


```csharp
public int GetCorrectAnswers()
{
    return correctAnswers;
}

public void IncrementCorrectAnswers()
{
    correctAnswers++;
}

public int GetQuestionsSeen()
{
    return questionsSeen;
}

public void IncrementQuestionsSeen()
{
    questionsSeen++;
}
```

`Get` 메서드는 값을 가져올 때 사용하고
`Increment` 메서드는 값이 1씩 증가해야 할 때 사용한다.



점수를 계산해주는 메서드도 작성해준다.
정수끼리 나누면 소수점이 사라질 수 있으므로, 하나의 값을 `float`으로 변환해준다.

```csharp
public int CalculateScore()
{
    return Mathf.RoundToInt(correctAnswers / (float)questionsSeen * 100);
}
```

`Mathf.RoundToInt()`는 소수점 값을 반올림해서 정수로 바꿔준다.
예를 들어 점수가 `66.6`이면 `67`로 표시된다.

# 66. 슬라이더



## 1. 슬라이더 추가

먼저 `Quiz Canvas` 아래에 `Slider`를 추가한다.

```text id="vfne33"
Quiz Canvas
└ Slider
```

슬라이더를 선택한 뒤 Inspector에서 다음 항목을 설정한다.

```text id="hq208h"
Transition → None
Direction → Left To Right
Whole Numbers → 체크
```
![](https://velog.velcdn.com/images/jihyun418/post/59bff77d-2810-41e4-a387-6b7c246de85a/image.png)


`Direction`은 슬라이더가 채워지는 방향을 의미한다.
현재는 왼쪽에서 오른쪽으로 진행되도록 `Left To Right`를 사용한다.

`Whole Numbers`를 체크하면 슬라이더 값이 소수점이 아니라 정수 단위로 움직인다.
퀴즈 문제 수는 정수이므로 이 설정이 적합하다.


### Slider 컴포넌트 주요 항목



```text id="ziis2h"
Fill Rect
→ 슬라이더가 채워지는 영역

Handle Rect
→ 사용자가 드래그하는 핸들 영역

Min Value / Max Value
→ 슬라이더 값의 최소, 최대 범위

Value
→ 현재 슬라이더 값

On Value Changed
→ 슬라이더 값이 바뀔 때 실행되는 이벤트
```

`On Value Changed`는 버튼의 `On Click()`과 비슷하게, 값이 변경될 때 특정 메서드를 실행할 수 있다.

## 2. Quiz 스크립트 코드 추가

퀴즈 스크립트에서 슬라이더에 접근할 수 있도록 변수를 추가한다.

```csharp id="rvcib7"
[Header("ProgressBar")]
[SerializeField] Slider progressBar;
```


**슬라이더 초기 설정**
`Start()`에서 슬라이더의 최대값과 시작값을 설정한다.

```csharp id="3w6tyl"
void Start()
{
    timer = FindObjectOfType<Timer>();
    scoreKeeper = FindObjectOfType<ScoreKeeper>();

    progressBar.maxValue = questions.Count; // 코드 추가
    progressBar.value = 0; // 코드 추가
}
```
`progressBar.maxValue`는 전체 문제 수로 설정한다.
`progressBar.value`는 아직 아무 문제도 풀지 않았으므로 `0`으로 시작한다.



**진행도 증가**
새로운 문제가 표시될 때마다 슬라이더 값을 1씩 증가시킨다.

```csharp id="rg6kxy"
void GetNextQuestion()
{
    if (questions.Count > 0)
    {
        SetButtonState(true);
        SetDefaultButtonSprites();
        GetRandomQuestion();
        DisplayQuestion();

        progressBar.value++; // 코드 추가
        scoreKeeper.IncrementQuestionsSeen();
    }
}
```
이렇게 하면 문제를 하나 볼 때마다 진행바가 한 칸씩 채워진다.


**게임 완료 상태 저장**
모든 문제를 풀었는지 확인하기 위해 `isComplete` 변수를 만든다.

```csharp id="go4irs"
public bool isComplete;
```

그리고 답을 선택한 뒤, 슬라이더 값이 최대값에 도달했는지 확인한다.

```csharp id="zx1hxo"
public void OnAnswerSelected(int index)
{
    hasAnsweredEarly = true;
    DisplayAnswer(index);

    SetButtonState(false);
    timer.CancelTimer();

    scoreText.text = "점수: " + scoreKeeper.CalculateScore() + "%";

    if (progressBar.value == progressBar.maxValue) // 코드 추가
    {
        isComplete = true;
    }
}
```

`progressBar.value`가 `progressBar.maxValue`와 같다면 모든 문제를 완료한 상태이므로 `isComplete`를 `true`로 바꾼다.

# 68. 게임 매니저



## 1. GameManager 오브젝트 생성

먼저 Hierarchy에서 빈 오브젝트를 생성한다.
그다음 Transform을 초기화하고 이름을 `GameManager`로 변경한다.

```text
GameManager
```

이후 `GameManager`라는 이름의 스크립트를 생성하고 만든 오브젝트에 추가한다.

---

## 2.GameManager 스크립트 작성

### 2-1. Quiz와 EndScreen 스크립트 가져오기

`GameManager`는 퀴즈 화면과 종료 화면을 제어해야 하므로, `Quiz`와 `EndScreen` 스크립트에 접근해야 한다.

```csharp
using UnityEngine;
using UnityEngine.SceneManagement;

public class GameManager : MonoBehaviour
{
    Quiz quiz;
    EndScreen endScreen;

    void Awake()
    {
        quiz = FindObjectOfType<Quiz>();
        endScreen = FindObjectOfType<EndScreen>();
    }

    void Start()
    {
        quiz.gameObject.SetActive(true);
        endScreen.gameObject.SetActive(false);
    }
}
```

`Awake()`에서는 씬에 있는 오브젝트와 컴포넌트를 찾아 연결한다.
`Start()`에서는 게임이 시작될 때 퀴즈 화면은 보이게 하고, 종료 화면은 숨긴다.

```csharp
quiz.gameObject.SetActive(true);
endScreen.gameObject.SetActive(false);
```

이 코드는 Unity Inspector에서 오브젝트 이름 옆의 체크박스를 켜고 끄는 것과 같은 역할을 한다.



### 2-2. 게임 종료 상태 확인하기

퀴즈가 끝났는지 확인하기 위해 `Update()`에서 `quiz.isComplete` 값을 검사한다.

```csharp
void Update()
{
    if (quiz.isComplete)
    {
        quiz.gameObject.SetActive(false);
        endScreen.gameObject.SetActive(true);
        endScreen.ShowFinalScore();
    }
}
```

`quiz.isComplete`가 `true`가 되면 퀴즈 화면을 숨기고, 종료 화면을 보여준다.
그리고 `ShowFinalScore()`를 호출해 최종 점수를 표시한다.



### 2-3. 다시 시작 기능 만들기

다시 시작 버튼을 누르면 현재 씬을 다시 불러오도록 만든다.
이를 위해 `SceneManager`를 사용한다.

```csharp
using UnityEngine.SceneManagement;
```

그리고 버튼에서 호출할 메서드를 작성한다.

```csharp
public void OnReplayLevel()
{
    SceneManager.LoadScene(SceneManager.GetActiveScene().buildIndex);
}
```

`SceneManager.GetActiveScene().buildIndex`는 현재 실행 중인 씬의 빌드 인덱스를 가져온다.
그 값을 `LoadScene()`에 전달하면 현재 씬을 다시 불러와 게임이 처음부터 시작된다.

## 마지막 문제에서 바로 종료되는 오류 수정

마지막 문제의 정답이 표시되기 전에 바로 종료 화면으로 넘어가는 문제가 발생할 수 있다.
이 오류는 `isComplete = true`가 너무 빨리 실행되기 때문에 생긴다.

기존에는 답을 선택하는 메서드 안에서 완료 여부를 확인했다.

```csharp
if (progressBar.value == progressBar.maxValue)
{
    isComplete = true;
}
```

하지만 이 위치에 있으면 마지막 문제의 정답을 보여주기 전에 게임이 끝날 수 있다.
따라서 타이머가 다음 문제를 불러오려고 할 때, 모든 문제가 끝났는지 확인하도록 위치를 변경한다.

```csharp
void Update()
{
    timerImage.fillAmount = timer.fillFraction;

    if (timer.loadNextQuestion)
    {
        if (progressBar.value == progressBar.maxValue)
        {
            isComplete = true;
            return;
        }

        hasAnsweredEarly = false;
        GetNextQuestion();
        timer.loadNextQuestion = false;
    }
    else if (!hasAnsweredEarly && !timer.isAnsweringQuestion)
    {
        DisplayAnswer(-1);
        SetButtonState(false);
    }
}
```

`return;`을 넣으면 게임이 완료된 경우 아래 코드가 더 이상 실행되지 않아서 오류를 방지할 수 있다.

## Awake와 Start의 차이

Unity에서는 `Start()`보다 `Awake()`가 먼저 실행된다.

  ![](https://velog.velcdn.com/images/jihyun418/post/309f561b-d95f-4a3e-814c-777cb7f69968/image.png)


따라서 씬에서 오브젝트를 찾거나 컴포넌트를 초기화하는 작업은 `Awake()`에서 하는 것이 좋다.
모든 스크립트의 `Awake()`가 먼저 실행된 뒤 `Start()`가 실행되기 때문이다.

이번 단계에서는 다음처럼 정리한다.

```text
Awake()
→ 오브젝트 찾기, 컴포넌트 연결

Start()
→ 화면 활성화 / 비활성화 같은 초기 상태 설정
```

그래서 `Quiz`, `EndScreen`, `GameManager`에서 오브젝트나 스크립트를 찾는 코드는 `Awake()`로 옮겨준다.

## 4. GameManager 최종 코드

```csharp
using UnityEngine;
using UnityEngine.SceneManagement;

public class GameManager : MonoBehaviour
{
    Quiz quiz;
    EndScreen endScreen;

    void Awake()
    {
        quiz = FindObjectOfType<Quiz>();
        endScreen = FindObjectOfType<EndScreen>();
    }

    void Start()
    {
        quiz.gameObject.SetActive(true);
        endScreen.gameObject.SetActive(false);
    }

    void Update()
    {
        if (quiz.isComplete)
        {
            quiz.gameObject.SetActive(false);
            endScreen.gameObject.SetActive(true);
            endScreen.ShowFinalScore();
        }
    }

    public void OnReplayLevel()
    {
        SceneManager.LoadScene(SceneManager.GetActiveScene().buildIndex);
    }
}
```
