### #50 게임디자인

#### concept
- Quiz game
- Answer a set number of multiple choice question
- Limited time to answer each question
- UI focused gameplay

#### game mechanics
- Mechanism to store and retrieve questions
- Buttons to select answers
- Timer to put some pressure on the player
- Progress bar to show how many question remain
- Scoring to show the player how well they did
- A way to restart the game when the quiz ends

#### game design
- player experience:
knowledgeable/intelligent
- core mechanic:
test your knowledge
- game loop:
answer a set number questions on a topic within the given time
